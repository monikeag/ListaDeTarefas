<p> 📝 Lista de Tarefas </p>
<p> Um aplicativo simples de lista de tarefas feito com <img src="https://img.shields.io/badge/HTML-239120?style=blue&logo=html5&logoColor=white">, <img src="https://img.shields.io/badge/CSS-239120?&style=blue&logo=css3&logoColor=white"> e <img src="https://img.shields.io/badge/JavaScript-F7DF1E?style=fblue&logo=javascript&logoColor=black">. Permite ao usuário adicionar tarefas com prioridade e status, exibindo visualmente com cores diferentes.</p>


💡 Funcionalidades

- Adicionar tarefas 
- Escolher a prioridade (Alta, Média, Baixa)
- Escolher o tipo de tarefa (Médica, Pessoal, Compras, Estudos)
- Exibição colorida por prioridade e status
- Campos limpos automaticamente após adicionar
- Legenda de tarefas.
